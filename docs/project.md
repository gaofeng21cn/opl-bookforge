# OPL Book Forge Project

Owner: `opl-bookforge`
Purpose: `domain_agent_project_overview`
State: `active_truth`
Machine boundary: Product scope; package identity and callable surfaces are declared in contracts.

OPL Book Forge serves authors, researchers, educators, and practitioners turning
source material into a nonfiction book. Its work includes storyline and reader
design, chapter planning and drafting, source/style review, figures and tables,
publication proof, and export handoff.

A book project retains its manuscript, source map, working/episodic/semantic
memory, review findings, artifact refs, and owner decisions through revision.
Book Forge owns their meaning, quality, and publication/export authority. OPL
Framework supplies shared execution and projection; the desktop App owns its
product experience.

Isolated papers, grants, presentations, and generic document formatting belong
to their respective domain owners. They enter Book Forge only when the requested
work belongs to an identifiable book project.

The canonical Agent and Package id is `obf`. The product is `OPL Book Forge`;
repository, domain, npm, and Codex carrier locators use `opl-bookforge`.

See [Architecture](./architecture.md) for execution structure and
[Status](./status.md) for evidence and current implementation limits.
