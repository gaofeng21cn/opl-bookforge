# OPL Book Forge Knowledge

Reusable book methods and policies live in this directory and are registered as
product-scoped entries in the OPL v2 durable knowledge catalog. Scope and content
kind are independent. User preferences, writing-topic experience, and project
knowledge retain their own owners and unique editable originals in an existing
personal library or ordinary working directory. OPL binds selected authorized
Markdown versions directly to one StageRun snapshot; Book Forge retains semantic
acceptance and book-quality authority. Chapter summaries are derived views with
source revisions, not new editable owners of personal knowledge.
